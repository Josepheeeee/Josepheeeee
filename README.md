## Working principles / 工作原则

- **Reproducible by default** — every public project has a small synthetic smoke path.
- **No hidden evaluation shortcuts** — splits, candidate sets, and exclusions are documented.
- **Readable experiments** — one clear entry point beats a folder of unexplained scripts.
- **Respect data boundaries** — raw data, credentials, submissions, and personal materials stay out of Git.
